# KB 知识库编译平台 — 系统功能清单

> 用途：客户工作量评估 / 报价依据。
> 范围：前台界面功能、后台对外接口（REST API）、MCP 能力、后台任务与内置引擎，全量覆盖。

## 一、平台概述

本平台是一套面向企业知识管理的**知识库构建与智能应用系统**。以「原始文档/数据表 → 解析入库 → 向量化检索 → 智能问答」为主线，提供从数据接入、知识加工、Wiki 知识库编排、知识图谱、智能问答到系统运维的完整闭环，并支持通过可视化编排引擎将「数据表 → Wiki 知识库」的构建流程自动化。

## 二、功能模块清单

### 模块 1：平台框架与访问控制

| 功能项 | 说明 |
|---|---|
| 登录认证 | 账号密码登录、登录态加密 Cookie、登录模式探测（本地/SSO）、记住密码 |
| 身份与会话 | 当前用户信息、团队信息、默认团队设置、团队切换 |
| 权限体系（RBAC） | 角色-菜单-接口三级授权；按用户角色动态渲染菜单；未授权页面/接口拦截 |
| 全局水印 | 页面水印（用户名+用户ID），防信息泄露 |
| 消息通知 | 站内通知（未读/全部、标记已读、全部已读、分页） |

后台接口：`/api/v1/auth/*`（登录/模式探测）、`/api/v1/me`、`/api/v1/system/*`（我的菜单/我的团队/切换团队/默认团队）。

### 模块 2：知识库管理

| 功能项 | 说明 |
|---|---|
| 知识库 CRUD | 创建/编辑/删除/列表（分页、关键字、文档数与页面数统计） |
| 知识库配置 | 向量存储选择（pgvector/预留 ES）、本体 Schema 绑定、模型绑定、检索配置 |
| 文档管理 | 上传（多格式）、下载、预览、删除（级联清理）、移动、重新解析、处理时间线查看 |
| 文档目录 | 文档目录树、目录增删改、批量移动 |
| 检索 | 向量检索、关键词检索、混合检索（RRF 融合） |

前台页面：`/kbs`（知识库列表）、`/kbs/[id]`（知识库详情：文档/Wiki/知识图谱 三视图）。
后台接口：`/api/v1/kbs` 全量（约 55 个端点：KB 增删改查、文档上传/删除/下载/预览/重解析、目录、检索、处理时间线）。

### 模块 3：文档解析引擎（docreader）

| 功能项 | 说明 |
|---|---|
| 多格式解析 | 3 大解析引擎覆盖 9 种格式：Markdown / PDF / Word / Excel / PPT / EPUB / MHTML / 图片等 |
| 分块处理 | 智能分块（大小/重叠可配置）、分块配置按知识库独立设置 |
| 解析器管理 | 解析引擎开关控制、引擎列表 |

后台接口：`/api/v1/chunking/*`（分块配置、切分预览、解析引擎列表）。

| 功能项 | 说明 |

| Wiki 目录 | list_wiki_folders / create_wiki_folder / update_wiki_folder / delete_wiki_folder | 目录树浏览、目录增删改 |
| 知识图谱 | wiki_graph / graph_add / graph_delete / graph_search_node | 图谱视图、节点/关系写入、子图删除、节点检索 |
| Wiki 治理 | wiki_stats / wiki_index_view / wiki_rebuild_links / wiki_lint / wiki_auto_fix / wiki_log / wiki_log_write / wiki_list_issues / wiki_update_issue_status | 统计、索引、重建链接、体检、自动修复、操作日志、问题清单与状态流转 |
| 基础工具 | tokenize | 中文分词（cut / cut_for_search，可带停用词） |

- **鉴权**：每个工具均要求 `sessionId`（平台会话标识），解析为平台用户后执行与 REST 一致的权限校验（知识库可见性：个人/团队/系统+管理员；写操作另需管理权限），未带有效 sessionId 一律拒绝——保证外部 Agent 无法越权访问。
- **传输**：streamable-http（独立部署容器 kb-mcp-server，经 nginx `/mcp/` 路由对外，支持 JSON-RPC initialize / tools/list / tools/call）与 stdio 双模式；接入方式与 WeKnora admin-kb 工具集对齐，外部 Agent 可平滑迁移。
- **集成场景**：供外部智能体（Agent）发现知识库、检索内容、读写 Wiki 页面、维护链接与图谱，实现"外部 Agent 直接操作平台知识库"的自动化和编排。
