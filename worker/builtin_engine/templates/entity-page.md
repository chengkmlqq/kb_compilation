# 基础实体页模板（entity-page.md）——市场监督管理法规域版

基础实体分两类：业务本体（b-）与规则本体（r-），模板不同。

## 一、业务本体页（Business Ontology）——知识卡片结构

page_type=`business_ontology`
slug=`entity-b-<md5(本体类别|canonical)[:10]>`（b=业务本体）
title=`<实体名>`
folder_id=`<业务本体类别子目录id>`（基础实体/业务本体/<序号>-<类别名>/ 下，9 类：1-法律法规/2-监管对象/3-许可事项/4-违法行为/5-行政处罚/6-监管职责/7-标准规范/8-程序事项/9-时限要求；如 监管对象类 → `基础实体/业务本体/2-监管对象/`）
source_refs=`[f"{kid}|{文件名}"]`
summary=`<一句话定位>`

### 卡片结构（自上而下）

```markdown
# <实体名>

<一句话定位>

（如：用于预防、治疗、诊断人的疾病，有目的地调节人的生理机能并规定有适应症或者功能主治、用法和用量的物质）
```

（注：本模板卡片结构不含**原文关联**节标题占位——原文关联节按来源文档分组生成；**不含「可回答问题」节，2026-08-28 用户要求所有模板去掉末尾可回答问题**）

### 要求
- **「关键规则」/「关联实体」两张表的行来源 = 规则驱动**（B2 主谓联合抽取后单通道：构建时规则卡约束对象→关键规则、规则 objects→关联实体，constraint/objects 与实体同批闭包配对保证命中）
- **内容必须来自切片原文**，来源信息由基本信息表的"来源制度"字段承载（《文件全名》第X条），**无独立"原文依据"节**——原文内容由"原文关联"的长句页承载，避免重复
- **来源制度一律用原始文件名**（如《进口药材管理办法.docx》），保持 file_name 原样（含扩展名），不得简写为"进口药材管理办法"；多条用 `；` 或分列
- **书名号防嵌套（2026-08-31 起强制）**：文件名本身已含《》的（法规文件名一般不含，《》多见于正文引用）不再额外包外层《》，统一用 `wr.bookname(file_name)` 包装（含《》原样返回、不含才包一层），禁止手写 `《{file_name}》`
- 关联实体关系类型常用：depends_on（依赖）/ triggers（触发）/ manages（管理职责）/ governs（治理）；用 `[[entity/b-xxx|名称]]` 双链

### 实体命名与分类（市场监督域，2026-09-04 定稿）

业务本体 9 类（BIZ_CAT_SHORT）：
1. 法律法规（法规文件本身/法律体系/立法层级：药品管理法、行政法规、部门规章）
2. 监管对象（被监管主体/事物/行为：药品、医疗器械、食品经营者、特种设备、网络交易平台）
3. 许可事项（需审批/许可/备案的事项：药品生产许可、食品经营许可、注册、备案）
4. 违法行为（违反法规的行为/情形：无证生产、虚假宣传、掺杂掺假）
5. 行政处罚（处罚种类/措施：罚款、没收违法所得、吊销许可证）
6. 监管职责（监管部门/机构/人员职责：市场监督管理部门、检验机构）
7. 标准规范（技术标准/规范/指南：强制性国家标准、行业标准）
8. 程序事项（执法/许可程序概念：立案、调查、听证、行政复议）
9. 时限要求（期限/期间概念：20个工作日、有效期5年）

**禁止**：纯日期/时间点（2025年9月1日）、介词引导动词短语、动作动词结尾描述、指示定语衍生表达（本法/本规定/本部门…）、条文序号/表格列名/条款引用。

### 原文关联
- 用实体名在长句清单匹配（text 含实体名即命中），直接引用真实长句 slug `[[longsentence/xxx|标题]]`，取前3条
- **按来源文档分组**，每组 `**《文档原始文件名》**` 粗体标题
- **原文关联为空是合理空置**（抽象概念无独立主题章节），判定标准：实体名在来源长句 title/content 中确无可匹配长句才允许为空

## 二、规则本体页（Rule Ontology）——单条规则卡

page_type=`rule_ontology`
slug=`entity-r-ro<编号>-<md5(canonical)[:10]>`（r=规则本体，ro=rule ontology）
title=`<规则标题>`（LLM 概括核心含义，≤20字）
folder_id=`<规则本体类别子目录id>`（基础实体/规则本体/<序号>-<类别名>/ 下，12 类：1-定义规则/2-条件规则/3-约束规则/4-职责规则/5-审批规则/6-流程规则/7-引用规则/8-例外规则/9-处罚规则/10-时限规则/11-版本规则/12-程序规则）
source_refs=`[f"{kid}|{文件名}"]`

### 卡片结构（自上而下）

```markdown
# <规则标题>

<规则类别>　<一句话定位>

| 字段 | 内容 |
|---|---|

| 约束对象 | [[entity/b-xxx|对象名]] |
| 关联对象 | <对象名（角色：主体/条件/动作/客体）> |
| 来源制度 | <《文件全名》第X条> |

## 规则结构

| 字段 | 内容 |
|---|---|
| 主体 | <…> |
| 条件 | <…> |
| 动作 | <…> |

## 原文关联

**《来源文件名》**

- [[longsentence/xxx|长句标题]]
```

### 要求
- **规则卡不设"关联实体"节**——约束对象列已链接业务实体，业务实体→规则的正向链接由业务实体页"关键规则"节承载
- **约束对象必须是业务实体名**（canonical 逐字等于同批 entities[].name），程序补链到 `[[entity/b-xxx|名]]`
- **evidence 字段**（原文关键片段，逐字来自长句）用于原文关联匹配；**无长句链接直接 SKIP**
- **规则卡不合并**（每篇法规的规则卡独立建页，rule_reg 已移除）
- 原件关联按来源文档分组；无「可回答问题」节
