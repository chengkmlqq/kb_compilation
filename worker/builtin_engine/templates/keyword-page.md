# 高频关键词页模板（keyword-page.md）——市场监督管理法规域版

page_type=`frequent_keyword`
slug=`keyword/<md5(canonicalize(词))[:10]>`（2026-08-31 起，同词跨文档合并到同一页）
title=`<词>`（不带前缀）
folder_ids=各来源文档的`<高频关键词目录id>`（多目录挂载）

## 结构（2026-08-31 起：多文档分组版——创建即合并，频次累加）

```markdown
# <词>

本关键词在 N 篇文档中高频出现（总频次：M）。

## 原文出现位置

**《文档A》**（频次：a）
| 序号 | 关联原文 |
|------|----------|
| 1 | [[longsentence/xxx|…关键词上下文片段…]] |
| 2 | [[longsentence/yyy|…关键词上下文片段…]] |

**《文档B》**（频次：b）
| 序号 | 关联原文 |
|------|----------|
| 1 | [[longsentence/zzz|…关键词上下文片段…]] |
```

## 要求

- **页面只含四部分**：标题（# 词）、开头句（几篇文档高频出现 + 总频次）、原文出现位置（按来源文档分组，每组一个两列表格）。**不含释义行**（市场域版 filter_terms_llm 无 meaning 字段，render_page_v2 无 meaning 参数）
- **禁止**在最后一个分组表格后追加任何内容（2026-08-28 用户要求去掉描述与「参见实体页」——关键词页不再链接实体页）
- **开头句**：`本关键词在 N 篇文档中高频出现（总频次：M）。`（N=来源文档数，M=Σ各文档词频）
- **分组标题**：`**《来源文件名》**（频次：a）`——文件名本身含《》时用 `wr.bookname()` 防嵌套（坑 97），频次为该文档内统计词频
- **原文出现位置表格**（每组）：
  - 表头两列：`序号` 和 `关联原文`
  - **关联原文 = 关键词上下文片段**（2026-08-28 用户要求，不展示完整长句）：以关键词为中心截取前后约 60 字，片段外以 `…` 标记省略；关键词在片段中**加粗**
  - 整格即为双向链接：`[[longsentence/xxx|…片段…]]`
  - 无匹配长句时保留表头、填 `| - | 暂无关联长句 |`
- 词频 N 来自新词发现统计（`discover_terms.py`，频次 ≥ min_freq 才建页）
- **创建即合并（2026-08-31 起）**：slug 由 canonical 确定性编码（`keyword/<md5(canonicalize(词))[:10]>`）；建页前查全库关键词注册表（`scripts/keyword_registry.py`），命中 → update 现有页（folder_ids += 本文档目录、source_refs += kid|文件名、原文出现位置按文档分组追加、频次累加）；未命中 → 新建
- **双轮 LLM 语义过滤（2026-08-31 起）**：第一轮 `filter_terms_llm.py` 单文档过滤（剔纯通用词）；第二轮 `filter_terms_global`（filter_terms_llm.py 内）对跨文档已存在词判断「是否放哪都有、无特殊业务含义」（如 管理/工作/要求）→ 剔除
- **模板门禁**：`python3 scripts/check_ls_template.py --kb <kb_id> --page-type frequent_keyword` 校验（开头句存在/分组标题格式/每组表头与表格完好/序号连续/无「参见实体页」/无表格后多余内容）
