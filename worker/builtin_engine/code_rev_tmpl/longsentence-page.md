# 长句原文页模板（longsentence 页）

- **slug**：`longsentence/<md5(kid)[:10]>-<md5(text)[:8]>`
- **page_type**：`original_sentence`
- **folder_id**：本文档版本目录下的「长句原文」

## 卡片骨架

```markdown
# 成本实体定义（CW_ST_001）

成本父实体，含营销机构成本、广告成本等 9 个子实体。

| 序号 | 原文 |
|---|---|
| 1 | CW_ST_001 成本 时间、地域标识、科目代码、科目名称、金额 成本父实体，包含营销机构成本、广告成本…网间结算成本 |
| 2 | CW_ST_002 营销机构成本 时间、科目代码、摊销周期… 中国移动公司专职从事营销活动的机构的费用支出成本 |
```

## 知识单元粒度（技术规范特有，2026-10-11 定稿）

| 文档形态 | 一个知识单元 = |
|---|---|
| 数据实体定义表 | **一个实体定义行**（实体编号+实体名+主要属性+说明，整行原文保留） |
| 实体关系/参照表相关行 | 一行关系/参照定义（含说明文字的行） |
| 外部接口 | **一个接口服务**（服务标识/名称/描述/交换方式/实现方式/性能要求/方法 + 数据集） |
| 元模型（附录一） | **一个元模型类**（Catalog/Schema/Table/Column/TransformationTask/InterfaceUnit/KPI 等） |
| 技术条款（性能/安全/时间/设备等） | **一条要求**（含阈值、条件、依据） |
| 叙述章节（术语/架构/流程/原则） | 一段完整语义（可跨句组合） |

**不进长句**：纯码值表（参照表码值 `00 娱乐类 01 体育类`、状态码/错误码清单）、纯字段清单行、章节标题、目录、页码、表头行。

## 硬性要求

1. `text` 数据层为纯原文 `\n` 拼接（slug=md5(text)，实体匹配与摘要回填都基于它）；页面呈现层 = `# 标题` + 一段汇总描述（summary）+ 两列表格（序号、原文）。
2. 每条原文逐字保留，仅 `|` → `\|` 转义、句内换行拍平为空格。
3. 单句单元（表格行/码值行以外的短单元）也必须保留原文，不添加解释性文字。
4. 门禁：`check_ls_template.py --page-type original_sentence`。
