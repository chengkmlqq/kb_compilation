# 分册索引页模板（index 页）

- **slug**：`index/<规范体系>-<分册>`（如 `index/中国移动省级NG2-BASS技术规范-总册`）
- **page_type**：`concept`（前端「原始文档 Wiki」Tab）
- **folder_id**：**分册目录**（不是体系根 —— 分册才是文档族）
- 由 `scripts/update_index.py` **确定性生成**（无 LLM，避免编造）

## 卡片骨架

```markdown
# 总册 分册索引

**规范体系**：中国移动省级NG2-BASS技术规范　·　**分册**：总册

## 版本清单

| 版本 | 摘要页 | 说明 |
|---|---|---|
| v5.0版 | [[summary/xxxxxxxx|<摘要标题>]] | （最新版本的分册定位首句） |
| v4.5版 | [[summary/xxxxxxxx|<摘要标题>]] | （该版本分册定位首句） |

## 分册在规范体系中的位置

（取自最新版本摘要「## 分册定位」段）

## 与兄弟分册的关系

| 相关文档 | 关系说明 | 原文依据 |
|---|---|---|
| [[summary/xxxxxxxx|逻辑模型分册 v5.0]] | 本规范的数据模型分册… | 「…」 |
```

## 硬性要求

1. 版本行按版本号倒序（无版本号者靠后）；同一版本目录多摘要取内容最长者。
2. 「与兄弟分册的关系」汇总各版本摘要关系表行并去重；无则写「（暂未从原文中发现与其他分册的明确引用关系）」。
3. 版本演进分析页**不生成**（本域明确舍弃）。
4. 门禁：`check_ls_template.py --page-type index`（必需节 `## 版本清单` + `## 与兄弟分册的关系`；wikilink slug 合法性）。
5. 每篇文档构建完成后自动更新该分册索引（`build_full.py` 步骤 11）。
