# 高频关键词页模板（keyword 页）

- **slug**：`keyword/<md5(canonicalize(词))[:10]>`（确定性编码 → 同词跨文档必同 slug、自动合并）
- **page_type**：`frequent_keyword`
- **folder_id**：本文档版本目录下的「高频关键词」（跨文档合并时累加 folder_ids）

```markdown
# 主题域
```

## 硬性要求

1. 开头句固定格式：`本关键词在 N 篇文档中高频出现（总频次：M）。`（N=来源文档数，M=Σ各文档词频）。
2. 原文出现位置**按来源文档分组**，每组标题 `**《文件名》**（频次：a）`（文件名含《》时用 `wr.bookname()` 防嵌套）。
3. 每行 = 关键词上下文片段（前后 ±60 字，首尾加 `…` 省略，关键词加粗），双链到长句页 `[[longsentence/...|片段]]`；不展示完整长句。
4. 片段内换行拍平为空格；清 `#` 标题残留与 `![](resource://…)` 图片标记；`|` 转义为 `\|`。
5. **不追加**「参见实体页」节。
6. 释义行（`**释义**`）由 LLM 生成，可选；旧页有释义时保留。
7. 门禁：`check_ls_template.py --page-type frequent_keyword`（表头/破表/序号连续/开头句/无参见实体页/纯通用词）。
