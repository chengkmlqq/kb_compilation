# 技术规范分册卡片（summary 页模板）

- **slug**：`summary/<md5(kid) 32位>`
- **page_type**：`summary`
- **folder_id**：该文档自己的**版本目录**（`<规范体系>/<分册>/<版本>`）
- **title**：文件名去扩展名（本身已含体系+版本+分册，如「中国移动省级NG2-BASS(v5.0)技术规范总册」）
- **source_refs**：`["<kid>|<源文件名>"]`（建页后必须 update 补写并读回核验）

## 硬性要求

1. **所有内容必须来自切片原文**，不编造。
2. 「关键技术要求」只收录带硬性约束的条款（应/必须/不得/小于/不少于/支持等），每条必须有逐字原文依据（页面直接可见原句，截约 45 字）。
3. 「与其他规范文档的关系」只列原文明确提到的规范文档关系（引用/依据/上下位/配套分册）；库内有对应文档用 `[[summary/<md5(kid)>|文档名]]` 双链，库内无则纯文本《引用名》；**禁止**「知识库中暂无对应文档」字样。
4. 「经实体关联推断的隐性关联分册」节：无隐性关联时**整体省略**（标题、提示、表头都不写）。
5. 禁止任何问候/聊天残留（`wr.clean_llm_tail` 清洗）；禁止 `\|` 转义竖线（落库前统一 `re.sub(r'\\\|', '|', content)`）。
6. 门禁：`check_ls_template.py --page-type summary` —— 必需节 `## 基本信息 / ## 分册定位 / ## 重点内容概览 / ## 关键技术要求 / ## 与其他规范文档的关系`。
